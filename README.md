# How to play to Heroes of Might and Magic III in Hungarian

1. Buy _Heroes of Might and Magic III Complete Edition_ on GOG (not the HD version)
1. Install the game
1. Download VCMI (free)
1. Install VCMI
1. When installing VCMI, specify the location of the base game's `Data`, `MP3`, and `Maps` folders.
1. Set the language to _Hungarian_
1. Install the _Magyar fordítás_ mod
1. Launch the game

# Hogyan játszhatsz a Heroes of Might and Magic III-mal magyarul

1. Vásárold meg a _Heroes of Might and Magic III Complete Edition_-t a GOG-on (ne a HD verziót)
1. Telepítsd a játékot
1. Töltsd le a VCMI-t (ingyenes)
1. Telepítsd a VCMI-t
1. A VCMI telepítésekor add meg az alapjáték `Data`, `MP3` és `Maps` mappáinak helyét.
1. Állítsd be a nyelvet _Magyar_-ra
1. Telepítsd a _Magyar fordítás_ modot
1. Indítsd el a játékot
